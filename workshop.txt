description=Real save slots for Project Zomboid. As many as you want, with whatever names you want. Quick Save without leaving the world. Full Save when you mean it. Branch runs, keep checkpoints, stop fearing the autosave.
description=
description=[b]Build:[/b] B42 only | [b]Platform:[/b] Windows 10/11 | [b]Singleplayer focus[/b]
description=
description=[hr][/hr]
description=
description=[h2]What you can do[/h2]
description=
description=[b]Saves[/b]
description=[list]
description=[*][b]Quick Save[/b] - Instant snapshot, no exit. Fast but partial (zombie/weather drift on reload). For testing.
description=[*][b]Full Save[/b] - Exits and flushes to disk. Slower, fully consistent. The safe default.
description=[*][b]Unlimited named slots[/b] - Branch runs, keep checkpoints, delete what you don't need.
description=[/list]
description=
description=[b]Management[/b]
description=[list]
description=[*]Rename / Duplicate / Delete from an in-game UI matching PZ style.
description=[*]Import vanilla saves with filters (All / Unimported / Imported), sort, and select-all.
description=[*]Auto thumbnails on every save.
description=[/list]
description=
description=[b]Recovery & rescue corrupted saves[/b]
description=[list]
description=[*][b]Edit Mods[/b] - Checkbox list of every active and installed mod. Pick what stays, what goes, what gets added. Creates a clone with custom mods.txt and a [b]_modded[/b] suffix - original untouched.
description=[*][b]Recovery flags[/b] - One-time fixes on next load: weather reset, time reset, zombie wipe, world repair. All stable.
description=[*][b]Save won't load anymore?[/b] Edit Mods handles broken mod dependencies, Recovery Flags handle a broken world state. Original save is never overwritten, so you can try combinations safely. Rescues a lot of runs.
description=[/list]
description=
description=[hr][/hr]
description=
description=[h2]Quick start[/h2]
description=
description=[olist]
description=[*]Subscribe and enable the mod in your world.
description=[*]Run [b]ManualSave_Watcher.cmd[/b] from the mod folder (Steam\steamapps\workshop\content\108600\3721602150\mods\ManualSaveMod\). A console window stays open in the background - this is required.
description=[*]In-game: ESC → Save Game → name it → Quick or Full.
description=[/olist]
description=
description=If the Save Game screen shows a red bar, the Watcher isn't running.
description=
description=[hr][/hr]
description=
description=[h2]Requirements[/h2]
description=
description=Windows 10/11, Project Zomboid Build 42, Borderless Windowed recommended (exclusive fullscreen can black-screen on Save and Return with some GPUs). Linux/macOS unsupported - Watcher uses Windows-only tools.
description=
description=[hr][/hr]
description=
description=[h2]Safety[/h2]
description=
description=No network access, no registry changes, no autostart, no bundled binaries. Plain-text .cmd and .ps1 scripts identical to the public GitHub source - open them in Notepad and read them yourself. Antivirus may heuristic-flag the .cmd (PowerShell + robocopy); the scripts are short and inspectable.

description=[h2]FAQ[/h2]
description=
description=[b]Watcher not running?[/b] Save list still loads, but every action is disabled with a red bar.
description=[b]Saves survive uninstall?[/b] Yes, backups live in Zomboid/ManualSaves/.
description=[b]Stale lock file after a crash?[/b] Delete [b]%USERPROFILE%\Zomboid\Lua\ManualSave_Watcher.lock[/b].
description=[b]Translations?[/b] Open a GitHub issue with your language file.
