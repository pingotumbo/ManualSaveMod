description=[h2]What this is for[/h2]
description=
description=You're about to walk into a police station full of zombies. You finally welded that car together. You're testing a mod-heavy run and want a clean exit if it gets weird. Vanilla PZ gives you one autosave per world, full stop. This mod gives you proper save slots: name them, branch them, keep three of them, delete the ones you don't need.
description=
description=For most situations [b]Full Save is what you want[/b]: it's the only one that exits and flushes everything to disk so the reload is consistent. Use Quick Save when you're testing, when you're about to do something dumb on purpose, or when zombie/weather drift is fine because you're going to reload immediately anyway. Full Save is slower because it has to exit and re-enter the world, that's the trade-off.

description=[h2]What you can do[/h2]
description=
description=[b]Core save system[/b]
description=[list]
description=[*][b]Quick Save[/b] - Instant snapshot without leaving the world. Ideal for testing or temporary checkpoints.
description=[*][b]Full Save[/b] - Exits the world and flushes everything to disk for a fully consistent backup.
description=[*][b]Multiple save slots per world[/b] - Create named checkpoints, branch runs, and maintain multiple timelines safely.
description=[/list]
description=
description=[b]Save management[/b]
description=[list]
description=[*][b]Rename / Duplicate / Delete[/b] saves from an in-game UI matching Project Zomboid style.
description=[*][b]Import vanilla saves[/b] into the slot system without rebuilding worlds.
description=[*][b]Auto thumbnails[/b] - Each save automatically stores a screenshot of the moment it was created.
description=[/list]
description=
description=[b]Recovery & safety tools[/b]
description=[list]
description=[*][b]Strip Mods[/b] - Remove mod dependencies from a save to recover broken modded runs.
description=[*][b]Recovery flags[/b] - One-time fixes on next load (weather reset, time reset, world repair tools).

description=[h2]What Quick Save does and does not capture[/h2]
description=
description=[b]Full Save is the safe default for almost every situation.[/b] Quick Save exists for testing, fast checkpoints, and cases where you don't care about world consistency because you're going to reload right away. A Quick Save reload may have:
description=
description=[list]
description=[*]Zombies in slightly different positions, sometimes uncomfortably close to you.
description=[*]Weather and time of day that doesn't quite match the moment you saved.
description=[*]Distant chunks in an older state.
description=[/list]
description=
description=[b]Full Save[/b] exits the game first so PZ can flush everything to disk, then copies. The copy is guaranteed consistent. [b]If you want zero surprises, always use Full Save.[/b] Quick Save is the fast escape hatch for testing and a little drift.
description=
description=[b]Practical pattern:[/b] Default to Full Save. Reach for Quick Save only when you're testing or about to reload immediately anyway. Duplicate a save before doing anything truly stupid.

description=
description=[list]
description=[*][b]Operating system:[/b] Windows 10 or Windows 11.

description=[h2]Is this safe?[/h2]
description=
description=This mod is intentionally designed to be transparent and easy to inspect.
description=
description=[list]
description=[*][b]No network access.[/b] The Watcher never opens sockets or connects to external services.
description=[*][b]No registry changes, services, or autostart.[/b] Closing the Watcher returns the system to its normal state.
description=[*][b]No executable patching.[/b] Project Zomboid itself is never modified.
description=[*][b]Plain-text scripts only.[/b] The Watcher is a short PowerShell script with comments. Open it in Notepad and inspect it yourself.
description=[*][b]No bundled binaries.[/b] No .exe files, DLLs, drivers, or external SDKs.
description=[/list]
description=
description=The included .cmd and .ps1 files are identical to the public GitHub source.
description=
description=If you want to verify integrity manually, compare hashes or inspect the source directly.
description=

description=[h2]Known issues[/h2]
description=
description=[list]
description=[*][b]Recovery Flag "Wipe Zombies" is experimental.[/b] Always test it on a duplicated save first.
description=[*][b]Exclusive fullscreen may cause a black screen[/b] during "Save and Return" on some GPU drivers. Borderless Windowed is recommended.
description=[*][b]Large worlds take time to copy.[/b] Saves above 300 MB may require several seconds to complete.
description=[*][b]Watcher lock file after crashes.[/b] In rare cases, a stale lock file may remain after an unexpected shutdown. Delete:
description=[b]%USERPROFILE%\Zomboid\Lua\ManualSave_Watcher.lock[/b]
description=if the Watcher refuses to start.

description=[h2]FAQ[/h2]
description=
description=[b]Will it work without the Watcher running?[/b]
description=No. The save list still loads and you can browse, but every action that touches the filesystem is disabled and a red bar reminds you the Watcher is offline.
description=
description=[b]Does it work on Linux or Mac?[/b]
description=No. The Watcher uses Windows-specific tools.
description=
description=[b]Can I import existing vanilla saves?[/b]
description=Yes. Open the Load screen from the main menu and click Import.
description=
description=[b]What's the difference between Quick Save and Full Save?[/b]
description=Quick Save = instant, partial state. Full Save = exits, fully consistent. Default to Full Save.
description=
description=[b]Will my saves survive a mod uninstall?[/b]
description=Yes. The backup folders under Zomboid/ManualSaves/ stay where they are.
description=
description=[b]Why does my antivirus complain?[/b]
description=Heuristic flag on "unsigned .cmd that calls PowerShell + robocopy". Read the scripts, they're short plain text.
